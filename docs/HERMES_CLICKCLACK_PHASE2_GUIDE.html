   feat/<MOBIUS_ISSUE_ID>-<SHORT_NAME>

8. Open a pull request to:
   Yongcheng123/hourly-dashboard-practice:integration/workshop

Never merge the PR yourself. Stop and ask if credentials or approval are needed.

5

主持人的 Review Agent 统一验收

主持人给 Review Agent GitHub 和 Mobius 权限后，再粘贴下面 Prompt。它会逐个检查和合并到 integration，并最终创建一个 main PR；最后是否合并 main 仍由真人决定。

Review Agent Prompt
You are the integration and review agent for the Hourly Dashboard workshop.

Repository: https://github.com/Yongcheng123/hourly-dashboard-practice
Mobius team: 周四练习 (THU)
Parent issue: THU-1
Participant PR base: integration/workshop
Final branch: main

1. Read the parent and all child issues.
2. Match every PR targeting integration/workshop to a child issue.
3. Verify allowed files, acceptance criteria, lint, tests, secrets, responsive
   layout, and accessibility.
4. Leave review feedback and update Mobius for incomplete or conflicting PRs.
5. Merge acceptable PRs into integration/workshop one at a time.
6. After each merge, rerun npm run lint and npm test.
7. Move the matching Mobius issue to Done and comment the merge commit.
8. Open one final PR from integration/workshop to main with a full summary.
9. Do not merge the final main PR; the human host makes that decision.

If access is missing, ask the host and stop. Never expose credentials.

主持人 60 分钟时间线

  • 0–15 分钟：Phase 1，Hermes Plugin + Bot 连接 + PONG。
  • 15–20 分钟：讲解 Repo、认领 THU-2–THU-9。
  • 20–45 分钟：各自开发、测试、PR、Mobius READY。
  • 45–55 分钟：Review Agent 验收并合入 integration。
  • 55–60 分钟：展示组合效果、最终 PR 和 Mobius 回顾。
